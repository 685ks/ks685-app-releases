# Kingdom 685 app (beta)

Android downloads of the Kingdom 685 app. Every release has one file, `kingdom685.apk`,
and the newest one is always at:

https://github.com/685ks/ks685-app-releases/releases/latest/download/kingdom685.apk

## Install with Obtainium (recommended)

[Obtainium](https://github.com/ImranR98/Obtainium) is a free app that installs apps straight
from their GitHub releases and tells you when there is an update.

1. Install Obtainium from its [releases page](https://github.com/ImranR98/Obtainium/releases)
   (the file ending in `.apk`) or from F-Droid.
2. On your phone, open this link: **[Add Kingdom 685 to Obtainium](https://apps.obtainium.imranr.dev/redirect?r=obtainium://app/%7B%22id%22%3A%22com.ks685.app%22%2C%22url%22%3A%22https%3A%2F%2Fgithub.com%2F685ks%2Fks685-app-releases%22%2C%22author%22%3A%22685ks%22%2C%22name%22%3A%22Kingdom%20685%22%2C%22additionalSettings%22%3A%22%7B%5C%22apkFilterRegEx%5C%22%3A%5C%22%5Ekingdom685%5C%5C%5C%5C.apk%24%5C%22%2C%5C%22includePrereleases%5C%22%3Afalse%7D%22%7D)**
   (or in Obtainium tap **Add app**, paste `https://github.com/685ks/ks685-app-releases` and tap **Add**).
3. Tap **Install**. Allow Obtainium to install apps when Android asks.
4. Updates show up in Obtainium. Tap **Update** when one does.

If Obtainium asks which file to use, pick `kingdom685.apk`.
Already have the app? Obtainium picks up the installed one, so you don't need to uninstall.

## Install by hand

1. Open the link above on your Android phone and download `kingdom685.apk`.
2. Open the file and allow installs from your browser when asked.
3. For updates, download and open the newest file again.

The app records the screen (backpack scan) only through Android's own
"Start recording?" prompt. It never needs "Display over other apps" or "Usage access".
